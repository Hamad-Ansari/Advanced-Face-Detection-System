## 📋 Project Overview

A professional, production-ready face detection system featuring:
- Real-time face detection with MediaPipe
- AI-powered age and gender prediction
- 468 facial landmarks tracking
- Modern, intuitive UI
- Comprehensive documentation

## 🎯 Key Features

### Core Functionality
✅ Real-time face detection (30+ FPS)  
✅ Multi-face tracking (up to 5 faces)  
✅ Age prediction (8 age ranges)  
✅ Gender classification  
✅ Confidence scoring  
✅ 468 facial landmarks  

### Technical Stack
- **Python 3.7+**
- **OpenCV 4.8.0+** - Computer vision
- **MediaPipe 0.10.0+** - Face detection
- **NumPy** - Numerical operations
- **Caffe Models** - Age/gender prediction

## 🚀 Getting Started

### Quick Install
```bash
git clone https://github.com/Hamad-Ansari/Advanced-Face-Detection-System.git
cd Advanced-Face-Detection-System
pip install -r requirements.txt
python run.py
```

### Download Models (Optional)
```bash
cd models
# Download from: https://github.com/opencv/opencv_extra/tree/master/testdata/dnn
```
